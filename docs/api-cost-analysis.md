## 🔍 **Google Places API 詳細コスト**

### **課金体系**
- **課金方式**: 従量課金制（リクエスト毎）
- **通貨**: USD（日本円換算: 1USD = 150円で計算）

### **主要API料金表**

| API種別 | 価格（USD） | 価格（円） | 無料枠/月 |
|---------|-------------|-----------|-----------|
| **Text Search** | $32/1000回 | ¥4,800/1000回 | なし |
| **Nearby Search** | $32/1000回 | ¥4,800/1000回 | なし |
| **Place Details** | $17/1000回 | ¥2,550/1000回 | なし |
| **Place Photos** | $7/1000回 | ¥1,050/1000回 | なし |

### **月間使用量予測**

#### **軽度利用（個人開発・テスト）**
```
想定利用: 月500回検索、500回詳細取得
- Text Search: 500回 × ¥4.8 = ¥2,400
- Place Details: 500回 × ¥2.55 = ¥1,275
月額合計: ¥3,675
```

#### **中度利用（小規模サービス）**
```
想定利用: 月2,000回検索、2,000回詳細取得
- Text Search: 2,000回 × ¥4.8 = ¥9,600
- Place Details: 2,000回 × ¥2.55 = ¥5,100
月額合計: ¥14,700
```

#### **重度利用（本格運用）**
```
想定利用: 月10,000回検索、10,000回詳細取得
- Text Search: 10,000回 × ¥4.8 = ¥48,000
- Place Details: 10,000回 × ¥2.55 = ¥25,500
月額合計: ¥73,500
```

### **コスト削減策**
1. **キャッシュ活用**: 30日間キャッシュ → 最大97%削減
2. **バッチ処理**: 複数店舗を一度に処理
3. **フィールド制限**: 必要な情報のみ取得
4. **地域限定**: 検索範囲を絞る

## 🌶️ **HotPepper API 詳細コスト**

### **課金体系**
- **基本料金**: 完全無料
- **API利用**: 無制限（利用規約内）
- **レート制限**: あり

### **利用制限**

| 項目 | 制限 |
|------|------|
| **リクエスト/秒** | 制限あり（具体値は非公開） |
| **リクエスト/日** | 制限あり（具体値は非公開） |
| **同時接続数** | 制限あり |
| **商用利用** | 要事前承認 |

### **実質コスト**
```
月額費用: ¥0
年額費用: ¥0
従量課金: なし

⚠️ 注意: 大量利用時は事前相談が推奨
```

### **利用上の注意**
- リクルート社の利用規約遵守が必要
- 大量アクセス時は事前相談
- サービス停止リスクあり
- データの商用利用は要承認

### **直接的コスト**
```
API料金: ¥0（APIなし）
スクレイピング: ¥0
月額費用: ¥0
```

### **間接的コスト**

| コスト項目 | 月額概算 | 説明 |
|------------|----------|------|
| **開発・保守** | ¥50,000～¥200,000 | スクレイピングシステム開発・維持 |
| **サーバーリソース** | ¥5,000～¥20,000 | プロキシ・処理サーバー費用 |
| **法的リスク対策** | ¥10,000～¥50,000 | 規約遵守・法的相談費用 |
| **データクリーニング** | ¥20,000～¥100,000 | データ整形・品質管理 |

### **技術的コスト**
- **開発時間**: 初期100-200時間
- **保守時間**: 月10-20時間
- **サイト変更対応**: 不定期で20-40時間

### **法的制約・リスク**
- **個人利用限定**: 商用利用は規約違反
- **アクセス頻度制限**: リスペクトフルアクセス必須
- **データ利用制限**: 基本情報のみ
- **帰属表示義務**: 適切なクレジット表示

## ⚠️ **リスクファクター**

### **コスト関連リスク**
- **料金改定**: API提供者の突然の値上げ
- **利用制限変更**: 無料枠の削減
- **為替リスク**: USD建て料金の変動

### **技術関連リスク**
- **API仕様変更**: 互換性の破綻
- **レート制限**: 利用量制限の強化
- **サービス停止**: API提供終了

### **法的リスク**
- **利用規約変更**: 突然の条件変更
- **著作権問題**: データ利用の制限
- **個人情報保護**: 規制強化
